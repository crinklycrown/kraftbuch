# Kraftbuch

Training & Ernährung als Web-App (PWA) – läuft offline, alle Daten bleiben lokal auf dem Handy.

- Gym: Pläne, Training mit Satz-Erfassung, Aufwärmsätzen, RIR, Pausentimer, Varianten/Ersatzübungen, Progression, Graphen
- Essen: Tagebuch, Lebensmittel, Gerichte, Fotos, Ziele für Trainings- und Ruhetage
- Export für Tag/Woche, Backup, Import aus Alpha Progression (CSV) und Futterbuch

App öffnen: https://crinklycrown.github.io/kraftbuch/
